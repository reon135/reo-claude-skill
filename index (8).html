スキルは何のために使う？

AIは賢くても、動画の作り方を毎回ゼロから考えると仕上がりがばらつきます。細かい長文プロンプトで補う手もありますが、毎回書くのは大変。その長文を丸ごと保存したものがスキルです。一度入れれば、短い一言で同じ品質を呼び出せます。

スキルなし10秒の動画を作って。文字は左寄せで大きく、登場は0.1秒ずつずらして、最後は少し弾ませて。色は3色まで、余白は広め。音は…（まだまだ続く）
→
スキルありhyperframes を使って、10秒の動画を作って
スキルの本体は SKILL.md という1枚の文章ファイル。AIはこれを読んでから作業を始めます。

スキルの中身をのぞくと

hyperframes/スキル1つ分のフォルダ
├ SKILL.md手順書。いつ使うか、どう作るか
├ scripts/AIが使う道具（小さなプログラム）
└ examples/お手本になる完成例

フォルダ名や中身はスキルごとに違います。共通点は SKILL.md が入っていること。

スキルとライブラリの違い

スキルはAIの「作り方」を変えるもの。ライブラリは動画に組み込まれる「素材」。ライブラリは必要なときAIが自分で取り込むので、名前を知っておくだけで役立ちます。

GitHubのページの見方（イメージ図）

見る場所は5つだけ

  • 1URL　ページの住所。AIに渡すときに使う
  • 2作者名 / 作品名　この組み合わせがリポジトリの名前
  • 3Star　いいねの数。人気の目安になる
  • 4Code ボタン　一式をZIPで保存できる
  • 5README　説明ページ。入れ方のコマンドがここに書いてある
英語だらけでも大丈夫。探すのは README の中の「Install」という見出しだけ。

      Q&A

      つまずきやすい所

      コマンドって何？ 黒い画面は必須？

      コマンドはパソコンへの命令文です。黒い画面（ターミナル）に打つのが本来の使い方ですが、Claude CodeやMuseのチャットに貼って「これを実行して」と頼めば、AIが代わりに実行してくれます。黒い画面を開かなくても進められます。

      ふつうのClaudeのチャットに貼っても入る？

      コマンドを実行してスキルを入れられるのは、Claude CodeやMuseのようにパソコンを操作できるAIです。ブラウザ版やアプリ版のClaudeのチャットは、ZIPファイルをアップロードする方式。入れ方の4つ目のタブを見てください。

      無料で使える？

      ここに載せたスキルとライブラリはGitHubで無料公開。ただしAI本体（MuseやClaude）の利用料や上限は別です。長い動画ほどAIの使用量が増える点に注意。

      npx でエラーになった

      Node.jsが入っていない可能性が高いです。AIに「Node.jsをインストールして」と頼んでからやり直してください。

      入れたのにスキルが使われない

      指示の中でスキルの名前を出すのが確実。「hyperframes を使って」のように書きます。Claude Codeなら「/」を打つと、入っているスキルの一覧が出ます。

      スマホだけでもできる？

      Museはクラウド上に自分用のパソコンを持つ仕組みなので、チャットで頼む方法ならスマホからも進められます。

      有料の教材や記事で紹介してもいい？

      リンクで紹介する分には問題になりにくいものの、中身を配る場合は各リポジトリのライセンスを確認してください。たとえばLemo-Opuscarは、スタイルの説明文が非商用ライセンスです。

      全部入れたほうがいい？

      入れすぎるとAIがどれを使うか迷いやすくなります。土台1つ、動き1つ、見た目か丸投げを1つ。まずは3つで十分。

      Museで本当に動く？

      Museが自分のスキルを読み込めること、スキル用フォルダに入れる手順は、利用者の公開レポートで確認しています。ただしこのページの作成時に各スキルをMuse上で動かす検証まではしていません。最初の1つで試してから増やすのが安全。

      最終確認 2026年11月16日。スター数や手順は変わることがあるため、入れる前に各リポジトリの説明を確認してください。画面の実演と動く見本はすべてイメージです。
